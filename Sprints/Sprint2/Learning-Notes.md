# Learning Notes – Sprint 02

## Overview

Sprint 2 focused on implementing the first business method in the `ApplicationService` class.

## Concepts Learned

- Learned how to define methods in Apex.
- Understood the purpose of method parameters.
- Learned why `static` methods can be called without creating an object.
- Learned the `Id` data type used for Salesforce record identifiers.
- Learned the `Date` data type for storing dates.
- Used `System.debug()` to display messages during execution.
- Learned how to execute Apex code using the Execute Anonymous Window.
- Learned how to read Debug Logs to verify the program output.

## Key Takeaways

- Methods help organize business logic.
- Parameters allow methods to receive different values each time they are called.
- Debug Logs are useful for testing and troubleshooting Apex code.
- Execute Anonymous is a convenient way to test Apex methods during development.
