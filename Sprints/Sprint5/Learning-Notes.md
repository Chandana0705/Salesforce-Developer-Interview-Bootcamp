# Learning Notes – Sprint 05

## Overview

Sprint 5 focused on creating and saving Application records in Salesforce using DML operations.

## Concepts Learned

- Learned how to create a new Salesforce record using Apex.
- Understood the purpose of DML operations.
- Learned how the `insert` statement stores records in the Salesforce database.
- Understood how to assign values to object fields before inserting records.
- Learned how exception handling works using `try-catch`.
- Used `System.debug()` to display success and error messages.

## Key Takeaways

- DML operations are used to manipulate Salesforce records.
- A record must be assigned all required field values before insertion.
- Exception handling prevents the application from failing unexpectedly.
- Proper error handling improves application reliability and debugging.
