# Reflection – Sprint 05

Sprint 5 introduced me to DML operations in Salesforce. I learned how to create a new Application record, assign values to its fields, and save it using the `insert` statement.

During this sprint, I also encountered practical issues such as missing required fields and data type mismatches. Resolving these issues helped me understand the importance of field validation and correct data types in Salesforce development.

Another important concept I learned was exception handling using the `try-catch` block. It allows applications to handle errors gracefully and makes debugging much easier.

Overall, Sprint 5 improved my understanding of record creation, DML operations, and error handling, which are fundamental concepts in Salesforce Apex development.
