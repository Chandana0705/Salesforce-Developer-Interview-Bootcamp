# Learning Notes – Sprint 08

## Overview

Sprint 8 focused on retrieving company eligibility details required for validating placement applications.

## Concepts Learned

- Learned how to retrieve a single Company record using SOQL.
- Understood how Apex stores query results in an object.
- Learned why only required fields should be selected.
- Understood how retrieved data is used in business validation.

## Key Takeaways

- SOQL retrieves records from Salesforce objects.
- Querying only necessary fields improves performance.
- Company eligibility information is essential before validating student applications.
- Efficient queries help stay within Salesforce governor limits.
