# Challenges – Sprint 06

Understanding why one large method should be divided into smaller methods.

### Solution

Learned that smaller methods improve readability, maintenance, and debugging while following clean coding practices.

## Challenge 2

Deciding which logic should be placed inside helper methods.

### Solution

Separated duplicate validation, eligibility validation, and application creation into individual methods based on their responsibilities.

### Solution

Understanding method reusability.

### Solution

Learned that helper methods can be reused from different parts of the application, reducing duplicate code and improving maintainability.
