# Sprint 06 – Refactoring Using Helper Methods

## 📌 Objective

The objective of Sprint 6 was to improve the maintainability and readability of the application by separating business logic into reusable helper methods.

---

## 📖 Business Requirement

Refactor the existing `submitApplication()` method by moving duplicate validation, eligibility validation, and application creation into separate helper methods. The application should continue to function as before while making the code cleaner and easier to maintain.

---

## 🛠️ Tasks Completed

- Refactored the `submitApplication()` method.
- Created helper methods for duplicate validation.
- Created helper methods for eligibility validation.
- Created a helper method for saving the application.
- Improved code readability and maintainability.
- Reduced code duplication.
- Verified that the application continued to work correctly after refactoring.
