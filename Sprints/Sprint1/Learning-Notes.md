# Learning Notes – Sprint 01

## Overview

Sprint 1 focused on setting up the Apex service layer for the Placement Management System by creating the initial `ApplicationService` class.

## Concepts Learned

- Learned what Apex is and its role in Salesforce.
- Understood the purpose of an Apex class.
- Learned how to create an Apex class using VS Code.
- Understood the meaning of the `public` access modifier.
- Learned how to deploy Apex code to a Salesforce org.
- Understood that this service class will contain the application's business logic in future sprints.

## Key Takeaways

- Apex classes help organize business logic.
- Using meaningful class names improves code readability.
- Sprint 1 established the foundation for the Placement Management System.
