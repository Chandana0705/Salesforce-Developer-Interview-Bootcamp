# Learning Notes – Sprint 11

## Overview

Sprint 11 focused on updating the status of an existing application after different stages of the recruitment process.

## Concepts Learned

- Learned how to retrieve an existing record using SOQL.
- Learned how to modify field values in Apex.
- Understood the purpose of the `update` DML statement.
- Learned how Salesforce updates existing records instead of creating new ones.
- Used try-catch blocks to handle update failures.
- Verified updates using Debug Logs.

## Key Takeaways

- The `update` statement modifies existing Salesforce records.
- A record must first be queried before it can be updated.
- Exception handling improves application reliability.
- Updating records is a common business operation in Salesforce applications.
