# Reflection – Sprint 03

Sprint 3 introduced me to SOQL and how Salesforce retrieves records from the database. I learned how to search for existing application records before allowing a student to submit a new application.

One of the most important concepts I learned was using Lists to store query results and using the `size()` method to determine whether matching records already exist. This helped me understand how duplicate validation is implemented in Salesforce applications.

Overall, this sprint strengthened my understanding of database queries, conditional logic, and data validation using Apex. These concepts are essential for building reliable Salesforce applications.
