# Challenges – Sprint 03

## Challenge 1

Understanding how SOQL differs from SQL.

### Solution

Learned that SOQL is specifically designed for querying Salesforce objects and uses object and field API names instead of database tables.

---

## Challenge 2

Understanding the purpose of the colon (`:`) in SOQL.

### Solution

Learned that the colon is used for variable binding, allowing Apex variables to be passed into SOQL queries.

---

## Challenge 3

Understanding why `existingApplications.size() > 0` is used.

### Solution

Learned that if the query returns one or more records, it indicates that a duplicate application already exists.

---

## Challenge 4

Understanding why query results are stored in a List.

### Solution

Learned that SOQL queries can return multiple records, so storing the results in a List is the appropriate approach.
