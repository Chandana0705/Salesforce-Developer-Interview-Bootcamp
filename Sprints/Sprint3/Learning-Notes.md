# Learning Notes – Sprint 03

## Overview

Sprint 3 focused on implementing duplicate application validation using SOQL queries.

## Concepts Learned

- Learned how to retrieve records using SOQL.
- Understood the purpose of the `WHERE` clause for filtering records.
- Learned how Apex variables are used inside SOQL with variable binding (`:`).
- Learned how to store query results in a List.
- Understood the use of the `size()` method to determine whether records exist.
- Learned to use `if-else` statements for decision-making.

## Key Takeaways

- SOQL helps retrieve only the required records from Salesforce.
- A List can store zero, one, or multiple records returned by a query.
- Using `size() > 0` is an effective way to identify duplicate records.
- Validating data before processing helps maintain data integrity.
