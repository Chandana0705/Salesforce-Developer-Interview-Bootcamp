# Learning Notes – Sprint 17

## Concepts Learned

- Bulkification
- Governor Limits
- Collections (List, Set, Map)
- SOQL Best Practices
- Enterprise Apex Design

## Key Learnings

- Apex Triggers must always assume multiple records.
- SOQL queries should never be placed inside loops.
- DML statements should never be placed inside loops.
- Set collections help remove duplicate IDs.
- Maps provide efficient access to queried records.
- Bulk-safe code improves application performance and scalability.
