# Challenges – Sprint 12

## Challenge 1

Ensuring every step executes in the correct order.

### Solution

Followed the workflow:
Receive Request → Retrieve Student → Retrieve Job → Check Duplicate → Validate Eligibility → Create Application → Save Record → Display Confirmation.

---

## Challenge 2

Understanding why DML should occur only after validation.

### Solution

Learned that inserting records before validation could result in invalid or duplicate data being stored.

---

## Challenge 3

Understanding how all previous sprints work together.

### Solution

Integrated every feature into one complete ApplicationService class and verified the complete workflow.

---

## Challenge 4

Maintaining readable code as the application grew.

### Solution

Used meaningful method names and organized the code logically to improve readability and maintainability.
