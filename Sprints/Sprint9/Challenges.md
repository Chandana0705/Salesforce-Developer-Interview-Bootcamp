# Challenges – Sprint 09

## Challenge 1

Understanding how to compare Student and Company field values.

### Solution

Retrieved both records using SOQL and compared their corresponding fields using conditional statements.

## Challenge 2

Understanding the purpose of multiple validation checks.

### Solution

Learned that every company defines different eligibility criteria, so each condition must be validated separately.

---

## Challenge 3

Understanding why the `return` statement is used.

### Solution

Learned that once a validation fails, there is no need to continue executing the remaining code.

---

## Challenge 4

Writing clear validation messages.

### Solution

Displayed meaningful debug messages to identify which eligibility condition failed.
