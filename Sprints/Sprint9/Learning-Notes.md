# Learning Notes – Sprint 09

## Overview

Sprint 9 focused on validating whether a student satisfies the company's eligibility criteria before processing the application.

## Concepts Learned

- Learned how to compare values from two different Salesforce objects.
- Understood how business rules are implemented using Apex.
- Learned the use of comparison operators.
- Learned how multiple conditions are evaluated sequentially.
- Understood why the `return` statement is used to stop execution when a validation fails.

## Key Takeaways

- Business validations improve data quality.
- Multiple conditions can be checked using `if` statements.
- Validation should occur before any DML operation.
- Using `return` avoids unnecessary execution after a failed validation.
