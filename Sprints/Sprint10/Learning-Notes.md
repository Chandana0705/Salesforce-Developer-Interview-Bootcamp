# Learning Notes – Sprint 10

## Overview

Sprint 10 focused on creating and saving an Application record after all business rules were successfully validated.

## Concepts Learned

- Learned how to create a new Salesforce object in Apex.
- Learned how to assign values to object fields.
- Understood how the `insert` DML statement stores records in Salesforce.
- Learned the importance of performing DML only after successful validation.
- Used try-catch blocks to handle exceptions during record insertion.
- Displayed meaningful messages for successful and failed operations.

## Key Takeaways

- DML is responsible for modifying Salesforce data.
- Business validation should always occur before inserting records.
- Exception handling makes applications more reliable.
- Clear confirmation messages improve user experience.
