# Challenges – Sprint 10

## Challenge 1

Understanding when to perform the DML operation.

### Solution

Learned that all business validations should be completed before performing the `insert` operation.

---

## Challenge 2

Encountered missing required field errors during record insertion.

### Solution

Verified the required fields in the Application object and assigned values before inserting the record.

---

## Challenge 3

Encountered data type mismatch errors.

### Solution

Matched the Apex variable data types with the corresponding Salesforce field data types before assigning values.

---

## Challenge 4

Understanding the purpose of exception handling.

### Solution

Used a try-catch block to capture DML exceptions and display meaningful error messages.
